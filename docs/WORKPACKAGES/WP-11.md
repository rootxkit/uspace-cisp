# WP-11: the operator console

Branch `feat/WP-11-web-console`. Milestone C-M3. Owns exclusively:
`web/app/[locale]/(console)/**`, `web/src/console/**`, the console
Playwright tests. Depends on WP-9 (scaffold and BFF), WP-8 (the console
API), WP-6 (deliveries), WP-5 (restrictions; the page degrades to "not
available" if its endpoints 404, with a test).

## What to build

- `/[locale]/console/login`: username, password, TOTP when the API
  says `mfa_required` (a first request without TOTP returns a problem
  that says so; the form then asks), lockout message with the time
  left, everything through the BFF.
- Shell with navigation by role (items hidden below the role, and the
  API's 403 still handled visibly), the status strip (datasets and
  versions, publishers with heartbeat age and stale flag, degraded
  components, the stream indicator), the account menu with logout.
- Publications: per dataset the version list (version, received,
  publisher, counts, reason, warnings, signature `kid`), a version
  page with the diff against its predecessor (added, changed with the
  path list, removed) and a map preview of the changed features, the
  refused attempts with their problems, and the `publisher_admin`
  action "republish current version" with a reason dialog.
- Restrictions: heads with state, window, airspace, ANSP version,
  events timeline, a map preview; the expiry job age and the ANSP
  staleness called out.
- Subscriptions: all clients' subscriptions with status, datasets,
  bbox preview, last success, consecutive failures; a subscription page
  with its deliveries (state, attempts, last code, next retry) and the
  attempt log; actions suspend, resume, retry delivery (reason dialog,
  role-gated).
- Accounts (`admin`): list, create (one-time password shown once with a
  copy button and a warning), role and status changes, MFA reset.
- Audit (`admin`): filtered, paged table of `events` with the actor and
  payload.
- Every action confirms with its consequence spelled out ("subscribers
  will receive a new change notification for version N") and requires
  a reason.
- ka and en throughout; dates shown in the viewer's zone with the UTC
  value on hover (`03` preamble: convert at the display layer only).

## Tests

- Vitest: role-based navigation (each role sees exactly its items), the
  diff renderer (bounded path list, truncated notice), the delivery
  state badges.
- Playwright against the mock API (extended with console fixtures):
  login with and without TOTP, lockout message; `viewer` cannot see
  action buttons and a forced request gets a visible 403; `publisher_admin`
  republishes with a reason and the audit page (as `admin`) shows the
  event; a subscription's failed delivery is retried; the restrictions
  page shows "not available" when its endpoints 404 (the WP-5 degrade
  test); both locales.

## Safety notes

The console must make it impossible to believe the CISP edits content.
No form edits a zone, a restriction or the USSP list; every action is
about subscriptions, deliveries, accounts or re-notification, and says
so. Staleness and degraded states are shown where the operator looks
first (the status strip), never only in a log.
