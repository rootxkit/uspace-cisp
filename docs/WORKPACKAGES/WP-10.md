# WP-10: the public zone map

Branch `feat/WP-10-web-public-map`. Milestone C-M1. Owns exclusively:
`web/app/[locale]/(public)/**`, `web/src/map/**`, `web/src/public/**`,
the public-map Playwright tests. Depends on WP-9 (scaffold) and WP-4
(`/public/v1/*`); WP-7's stream for live refresh (degrades to polling
`HEAD` when the stream is absent, so WP-7 is not a hard dependency).

## Read first

1. `CLAUDE.md`, `docs/PLAN.md §6.3` (headers, `cis_*` members,
   `cis_applicability: unknown`), `§6.4`, `§6.5` (stream frames), `§15`
   Q10.
2. Spec `01 §2` C1 (public read-only, rate-limited, cacheable), `02 F3`
   (every response carries the update time and version: Art. 9(2)),
   `07` C-M1 ("the public map shows the zones"), `08` Q15.
3. `uspace-ui`: the map component (viewport, tile sources, bbox

4. ED-318 fields the map explains: `type`, `reason`, `message`,
   `limitedApplicability`, `zoneAuthority` (purpose, contact), the
   layer's limits and references, `extendedProperties.cis_restriction`,
   `cis_applicability`.

## What to build

- Page `/[locale]` (the public map): the kit's MapLibre map centred on
  a configured view (`NEXT_PUBLIC_MAP_CENTER`, `NEXT_PUBLIC_MAP_ZOOM`;
  never a hardcoded coordinate — INV-03 applies to the UI too), with
  three layers from `/public/v1/zones`, `/public/v1/uspace_airspace`,
  `/public/v1/restrictions` fetched by the viewport bbox through the
  kit's hook (debounced, `If-None-Match` honoured by the browser cache),
  styled by the kit's symbology (type, and for restrictions the
  `cis_restriction.state`), a legend, a layer toggle, and a feature
  panel on click that renders the ED-318 properties with the vertical
  limits **in their own reference** (never converted; "0 m AGL - 120 m
  AGL", "600 m AMSL - 800 m AMSL", "1 000 ft AMSL" when published in
  feet), the applicability schedule as published (days, times with
  their offsets, daylight events by name), the authority contacts, and
  the restriction window and state.
- An "as of" banner: per dataset `cis_version` and `cis_updated_at`
  (Art. 9(2)), the publisher staleness when `cis_publisher_stale_since`
  is present, and a visible "live / polling / disconnected" indicator
  from the stream (WP-7) or from the fallback `HEAD` every 60 s; a
  `resync` or a changed `ETag` refetches the visible bbox. A dataset the
  API cannot serve (503, `X-CIS-Stale`) is shown as "unavailable since"
  on the banner, never as an empty sky (LESSONS E-02 corollary; the
  spec's failure rule).
- A time control: "show zones applicable at <now | a chosen instant>"
  using `?at=`; features with `cis_applicability: unknown` are drawn
  with the kit's "unknown" style and the panel says why it could not be
  evaluated.
- The USSP list page `/[locale]/ussps` from `/public/v1/ussp_list`
  (name, services, limitations, validity, terms link).
- ka and en for every string; numbers and dates formatted per locale;
  the Georgian font everywhere.
- Accessibility: keyboard reachable panel and controls, ARIA labels
  from the catalogue, colour choices from the kit (no new colours
  here).

## Tests

- Vitest: the property formatter (limits in their own reference; feet
  stay feet; a missing limit shows "unbounded"; an `unknown`
  applicability shows the reason), the schedule formatter against the
  `zones_applicability.json` inputs (rendered text contains the days
  and times as published), the banner state machine (live → polling →
  disconnected → unavailable).
- Playwright against the mock API (`web/test/mock-api.mjs` serving the
  `ed318_roundtrip.json` base collection and a restriction): the three
  layers render, clicking a zone opens the panel with the right
  identifier and limits, the `at=` control hides a zone outside its
  window and keeps the `unknown` one with its style, a 503 from the mock
  turns the banner to "unavailable since", a changed `ETag` on `HEAD`
  triggers a refetch (assert the request), both locales.

## Safety notes

The map must never imply more than the data says: a limit is shown in
its own reference with no conversion, a zone that cannot be evaluated
is shown as unknown rather than hidden, and an API outage is shown as an
outage rather than as clear sky. There is no judgement in this page;
if you find yourself computing whether a point is inside a zone, stop:
that belongs to the consumer's Go code.
